# بازیابی معکوس تحریک مدل دهم

این مجموعه فقط از وزن ثابت مدل دهم استفاده می‌کند.
آموزش یا تغییر معماری انجام نشده است.
تک‌منبعی، دومنبعی، ورودی نرم بایگانی‌شده و دادهٔ نویزی بررسی می‌شوند.
آزمایش ابهام علامتِ قطعه‌ای نیز مستقل از شبکه انجام می‌شود.

## بازتولید

از ریشهٔ Master_Magnetic، در Python 3.12 اجرا کنید:

```sh
OPENBLAS_NUM_THREADS=1 python -m unittest discover -s tests -p test_inverse.py -v
OPENBLAS_NUM_THREADS=1 python scripts/operator/validate_inverse.py --output results/operator_inverse
```

وابستگی‌ها PyTorch، NumPy و SciPy موجود پروژه هستند.
تنظیمات ثابت پیش از برازش در `predeclared_config.json` ثبت شده‌اند.
فایل‌های موجود با همان تنظیمات بازاستفاده می‌شوند.
برای تغییر بودجه یا تنظیمات، پوشهٔ خروجی تازه انتخاب کنید.
گزینهٔ `--only` برای اجرای مستقل هر نمونه است.
اجرای نهایی بدون این گزینه، جدول جامع را تولید می‌کند.
در اجرای ثبت‌شده، سه نمونه هم‌زمان روی CPU اجرا شدند.
هر فرایند فقط یک رشتهٔ PyTorch و OpenBLAS داشت.

## تنظیمات

هفت گره و پنجرهٔ `0.0125` حالت پایه هستند.
سه شروع غیرصفر برای A، B و C اجرا می‌شوند.
برای مقایسه‌های حساسیت و نویز، دو شروع ثبت می‌شود.
سقف بودجه برای هر شروع ۹۰ تکرار است.
این سقف، تضمین همگرایی بهینه‌ساز نیست.
حساسیت شامل ۱۳ گره، نصف پنجره، وزن محوری و زبری است.
کف مقیاس خطا از بیشینه‌های ارزیابی مستقیم بایگانی‌شده انتخاب شد.
این کف‌ها تضمین دقت عملگر برای تحریک بازیابی‌شده نیستند.

A با پیشینِ «فقط منبع چپ، علامت مثبت» اجرا می‌شود.
B بدون اطلاع از علامت یا تحریک مرجع برازش می‌شود.
C از مختصات حل عددی `05_source_switch.csv` استفاده می‌کند.
فرمول نرم اصلی، فقط در ارزیابی و تولید مرجع استفاده می‌شود.
مشاهدات sparse شامل هر چهارمین نمونه و هر دو انتها هستند.
نویزهای `0.05` و `0.2` میکرومتر برای هر مؤلفه اعمال شدند.
seedهای ازپیش‌ثابت `1103` و `2907` برای هر سطح استفاده می‌شوند.
نویز فیزیکی به `sigma_X=sigma_m/R` و `sigma_Z=sigma_m/D` تبدیل می‌شود.
وزن هر مؤلفه، بیشینهٔ نویز و کف عملگر را به‌کار می‌برد.
شرط اولیه در تمام این آزمون‌ها دقیق باقی می‌ماند.
پارامترهای سیال نیز معلوم و ثابت‌اند.

## فایل‌ها و معیارها

- `summary.json` و `summary.csv`: تمام نمونه‌های ازپیش‌تعریف‌شده، شامل شکست‌ها.
- `observations.csv`: تنها داده‌های موقعیت واردشده به برازش.
- `fit_report.json`: تمام شروع‌ها، هدف، جریمه‌ها، توقف و ضرایب خام.
- `knots.csv`: زمان گره‌ها و ضرایب خام منتخب.
- `controls.csv`: مرجع، تخمین خام و تخمین با علامت کلی هم‌تراز.
- `replay.csv`: مرجع پاک، پیش‌بینی شبکه و بازپخش مستقل ضرایب خام.
- `report.json`: تنظیمات، مقیاس‌ها، خطاها، قیود و تمام بازپخش‌های شروع‌ها.
- `field_common_positions.csv`: میدان و نیرو در نقاط مرجع مشترک.

هر دو مؤلفهٔ موقعیت، RMSE و بیشینهٔ خطای جداگانه دارند.
مقایسهٔ نویز، هم با دادهٔ نویزی و هم مرجع پاک ثبت می‌شود.
میدان در مقیاس `B/BS` و نیرو در `F/(ALPHA*BS^2/D)` هستند.
نیرو و میدان روی `q_ref(tau)` مقایسه می‌شوند.
این آرایه‌ها ادعای بازیابی مستقل کل میدان فضایی نیستند.
علامت هم‌تراز، یک علامت مشترک برای تمام زمان‌ها و منابع است.
بازپخش اصلی همواره از ضرایب خام استفاده می‌کند.
خطای تحریک صفر با معیار مطلق سنجیده می‌شود.

هر شروع با حل مستقل DOP853 نیز ارزیابی شده است.
گام بیشینهٔ مرجع از `0.002` به `0.001` ثانیه نصف می‌شود.
تلرانس‌های اصلی DOP853 حفظ شده‌اند.
رویداد خروج از دامنه به‌عنوان شکست بازپخش گزارش می‌شود.
پهنای مشترکِ صفر در آزمایش E، ابهام علامت موضعی ایجاد می‌کند.
نشانهٔ قبل از این فاصله، علامت پالس بعدی را مشخص نمی‌کند.

وضعیت `completed` فقط به اجرای محاسبات و بازپخش اشاره دارد.
این وضعیت، قبولی دقت تحریک یا همگرایی بهینه‌ساز نیست.
آستانهٔ قبولی تازه‌ای بر پایهٔ پاسخ‌های آزمون تعیین نشده است.
خطاهای بزرگ و توقف در سقف تکرار نیز در نتایج حفظ می‌شوند.
اعتبارسنجی مستقیم قبلی با این مطالعه تغییر نمی‌کند.

`implementation_checks.txt` نتیجهٔ آزمون‌های سازگاری و گرادیان را نگه می‌دارد.
`implementation_diagnostics.json` زمان گرادیان و ناوردایی علامت شبکه را ثبت می‌کند.
خطای تقارن شبکه، شاهد تعیین‌پذیری فیزیکی نیست.
یک خطای اولیهٔ سریال‌سازی پیش از ثبت نتایج اصلاح شد.
گزارش آن در `development_serialization_failure.json` برای شفافیت حفظ شده است.
