# Magnetic particle path tracking — Master8 extension

این پروژه نسخهٔ اصلی آخرین نوت‌بوک Kaggle و یک کنترل‌کنندهٔ بازخوردی آموزش‌دیده برای دنبال‌کردن مسیر ذره را نگه می‌دارد.

- نسخهٔ دست‌نخورده: `notebooks/master8_original.ipynb`
- منبع: https://www.kaggle.com/code/mohrezsayeh/master8-general-magnetic-particl-2ndtry
- وزن‌های سیال، میدان و ذره از Master8 استخراج شده‌اند؛ سیاست معکوس جدید در `checkpoints/inverse_policy.pt` آموزش داده شده است.
- مدل ذرهٔ پنج‌ضریبی قدیمی فقط برای حفظ سابقه نگه داشته شده؛ کنترل جدید از میدان‌های آموزش‌دیده و سیاست معکوس استفاده می‌کند و به پنج ضریب محدود نیست.

## اجرا

Python 3.12 توصیه می‌شود. برای CPU می‌توانید اول PyTorch را از مخزن CPU نصب کنید.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python scripts/track_path.py examples/bump.csv --output results/custom
python scripts/validate.py
```

آموزش مجدد سیاست کنترل، بدون آموزش مجدد میدان‌ها:

```bash
python scripts/train_policy.py --steps 2500
```

## مسیر دلخواه

فایل CSV با عنوان `z_m,x_m` و حداقل چهار نقطه بدهید. همهٔ واحدها مترند. ستون طولی باید صعودی باشد. مسیر از `z=-0.08 m, x=0` شروع می‌شود؛ آخر مسیر حداکثر `z=0.072 m` است. مختصات عرضی باید در بازهٔ باز ±52.5 میکرومتر باشد. نمونه‌ها در `examples/` هستند.

برای مسیر عرضیِ زمان‌دار از عنوان `time_s,x_m` و `--mode time` استفاده کنید. زمان باید از صفر شروع شود و از 5.0666667 ثانیه بیشتر نشود. زمان‌بندی طولی مستقل قابل تحمیل نیست.

خروجی `control.csv` شامل مسیر، زمان، فرمان محدود `u`، سمت منبع، مقیاس تحریک، بزرگی میدان و نیروهای مغناطیسی است. `report.json` خطا، اشباع و نتیجهٔ پذیرش را گزارش می‌کند. ورودی نامعتبر خطا می‌دهد؛ مسیر غیرقابل‌دنبال‌کردن با `accepted=false` و خروج ناموفق رد می‌شود.

## آموزش و اعتبارسنجی

سیاست معکوس از ۶۰هزار نمونهٔ حالت/فرمان، با برچسب‌گذاری از میدان‌های PINN آموزش‌دیده ساخته شده است. آموزش به مسیر هدف خاص وابسته نیست. بازخورد وضعیت جاری ذره و شیب مسیر را به فرمان تبدیل می‌کند. این روش یک PINN جدید برای مسیر یا یادگیری تقویتی نیست.

گزارش آموزش شامل آزمون ۱۲هزار حالت مجزا است. `scripts/validate.py` میدان‌ها را با مرجع تحلیلی، سپس مسیرهای دیده‌نشده را هم با میدان‌های یادگرفته‌شده و هم با فیزیک تحلیلی مستقل مقایسه می‌کند. فرمان‌ها جداگانه در حل مستقل بازپخش می‌شوند. یک آزمایش با افزایش ۱۰٪ جریان و یک مسیر غیرقابل‌اجرا نیز وجود دارد. آستانهٔ خطای عرضی در این آزمایش‌ها ۰٫۷۵ میکرومتر است. گزارش‌های واقعی در `results/` ثبت شده‌اند.

## محدودهٔ فیزیکی

این یک مدل دوبعدی نظری و یک‌طرفهٔ جریان/میدان/ذره است: شعاع کانال ۷۵ میکرومتر، شعاع ذره ۵۰۰ نانومتر، جریان اسمی ۰٫۰۱۵ متر بر ثانیه، سیال نیوتنی، و حرکت بیش‌میرا. موقعیت لحظه‌ای در بازخورد بدون نویز و تأخیر فرض شده است. تغییر خواص ذره، هندسه یا منبع نیازمند آموزش/اعتبارسنجی مجدد است.

`u` یک تحریک مؤثر با `|u|<=0.5` و انتخاب بین دو منبع آینه‌ای است؛ علامت آن به معنی معکوس‌کردن قطب یک آهنربا نیست. مقیاس منبع `sqrt(abs(u))` است. برای سیم‌پیچ واقعی، منحنی جریان-میدان، هندسه، محدودیت نرخ تغییر، اشباع و حسگر موقعیت باید اضافه شوند. نتایج حاضر اثبات تجربی یا تضمین دنبال‌کردن هر مسیر نیستند.
