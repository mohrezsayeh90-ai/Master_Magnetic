# master9 — پارامتری‌سازی فیزیکی با سرعت اولیهٔ ذره

نسخهٔ جدید: https://www.kaggle.com/code/mohrezsayeh/master9

این نسخه از کنترل‌کنندهٔ نظارت‌شدهٔ قبلی جداست. هیچ مسیر حل‌شده، پاسخ فرمان، یا خروجی حل‌گر عددی وارد آموزش نمی‌شود. شبکهٔ سیال با باقیماندهٔ معادلهٔ مومنتوم و قید دبی آموزش می‌بیند. PINN ذره از معادلهٔ اینرسی–درگ، میدان منبع و شرایط اولیه استفاده می‌کند. کنترل مسیر، حل معکوس مقید همین شبکه است. **تابع میدان مغناطیسی در این نسخه تحلیلی و با هندسهٔ ثابت است؛ شبکهٔ جدیدی برای حل ماکسول آموزش داده نمی‌شود.**

## ورودی‌ها و محدوده

| پارامتر | محدوده | آزمون فیزیکی |
|---|---|---|
| ویسکوزیته eta | 0.001–0.006 Pa.s | مقایسهٔ حرکت با Radau و نسبت وارون ویسکوزیته در تحرک مغناطیسی |
| سرعت متوسط سیال U | 0.005–0.03 m/s | پروفایل پوازی، دبی و حل مستقل در دو حد سرعت |
| چگالی سیال rho | 950–1100 kg/m³ | سازگاری Re، جرم افزوده و استقلال پروفایل پایای بی‌بعد از چگالی |
| رینولدز Re | محدودهٔ حاصل 0.11875–4.95 | Re=rho U(2R)/eta؛ ترکیب نامعتبر رد می‌شود |
| مختصات عرضی رهایش X0=x0/R | -0.7 تا +0.7، برابر ±52.5 µm | شرط اولیهٔ دقیق در گوشه‌های دامنه و مقایسه با حل مستقل |
| مختصات طولی رهایش Z0=z0/d | -2 تا +1.7، برابر -80 تا +68 mm | شرط اولیه و آزمون رهایش جابه‌جاشده |
| سرعت اولیهٔ عرضی ذره vx0 | -0.001 تا +0.001 m/s | شرط سرعت اولیه و میرایی استوکس در زمان‌های بسیار کوتاه |
| سرعت اولیهٔ طولی ذره vz0 | 0 تا 0.06 m/s | همان آزمون سرعت و مقایسه با Radau اینرسی‌دار |
| تحریک مؤثر u | -0.5 تا +0.5 | محدودیت دامنه و بازپخش فرمان در حل مستقل |

Re و eta مستقل از یکدیگر به شبکه داده نمی‌شوند. API ورودی `Re,U,rho` را می‌گیرد و eta را محاسبه می‌کند؛ سپس محدودهٔ eta بررسی می‌شود. پارامترها طی هر اجرای مسیر ثابت‌اند. تغییر زمانی ویسکوزیته/جریان آموزش داده نشده است.

## معادلات و مقیاس‌ها

R=75 µm، d=40 mm، شعاع ذره=500 nm، چگالی ذره=5200 kg/m³ و مقیاس زمان d/(2 Uref)=1.333333 s با Uref=0.015 m/s ثابت‌اند.

پروفایل سیال `v_z=2U w((x/R)^2)` است. شبکهٔ مشترک w با معادلهٔ `q w''+w'+1=0`، شرط عدم لغزش و قید دبی آموزش می‌بیند. شکل بی‌بعد جریان کاملاً توسعه‌یافته به Re وابسته نیست؛ این تقارن در معماری اعمال شده و U، Re و eta در تبدیل به واحد فیزیکی وارد می‌شوند. این یک حل عمومی برای جریان ورودی در حال توسعه، تلاطم یا سیال غیرنیوتنی نیست.

ذره: `dq/dtau=V` و `epsilon dV/dtau=F(q,u,parameters)-V`؛ F سرعت نهایی حاصل از جریان و نیروی مغناطیسی است. epsilon از زمان آرامش `(m_particle+0.5*m_displaced_fluid)/(6 pi eta rp)` به دست می‌آید. شبکه شرط‌های مکان و سرعت اولیه را دقیقاً اعمال می‌کند. مؤلفهٔ نمایی گذرای سریع به‌صورت تحلیلی در ansatz قرار دارد؛ بخش اصلاحی کند با باقیماندهٔ معادلات آموزش می‌بیند.

حدود زمان آرامش با چگالی مرجع 1000 حدود 0.053–0.317 میکروثانیه است. بنابراین انتظار فیزیکی این است که اثر سرعت اولیه بسیار سریع میرا شود؛ اثر آن روی مکان بسیار کوچک است. **نیروی تاریخچهٔ Basset لحاظ نشده است؛ آزمون گذرا اعتبار مدل ساده‌شده را می‌سنجد، نه دقت تجربی در این مقیاس زمانی.** گرانش، دیواره بر درگ، برهم‌کنش دوطرفه، نویز و تأخیر حسگر نیز لحاظ نشده‌اند.

PINN یک نگاشت محلی با افق حداکثر 0.033333 s را آموزش می‌بیند؛ مسیرهای طولانی با تکرار آن و بررسی مستقل ساخته می‌شوند. در کنترل مسیر، محدودیت مکان |X|<=0.7 و Z<=1.7 اعمال می‌شود. مسیر نمونه تا Z=1.4 می‌رود تا حاشیهٔ خروج از دامنه داشته باشد.

## اجرا

```bash
pip install -r requirements.txt
python scripts/master9/run.py --train --require-gpu --output results/master9
```

پس از دریافت وزن‌های اجرای Kaggle در `results/master9/checkpoint.pt`:

```bash
python scripts/master9/run.py --output results/master9
python scripts/master9/run.py --output results/master9 --path my_path.csv \
  --Re 0.8 --mean 0.015 --rho 1000 \
  --x0 0 --z0 -0.08 --vx0 0.0005 --vz0 0.02
```

CSV مسیر دارای عنوان `z_m,x_m`، حداقل چهار نقطهٔ متناهی و z صعودی است. شروع باید با محل رهایش سازگار باشد؛ |x|<52.5 µm و آخر z حداکثر 56 mm است. مسیر دلخواه صرفاً به‌دلیل معتبر بودن فایل شدنی نیست؛ خطای نهایی و محدودیت‌ها بررسی می‌شوند.

آزمون‌ها پیش از مشاهدهٔ خروجی GPU تعریف شده‌اند. شکست معیارها اجرای نوت‌بوک را متوقف می‌کند. فایل `physics_tests.json` نتایج هر پارامتر و `control_tests.json` نتایج مسیرهای جدید را گزارش می‌کنند. `training.json` دستگاه واقعی GPU، نسخهٔ PyTorch، زمان و تعداد تکرارهای واقعی را ثبت می‌کند. دادهٔ حل مستقل در آموزش صفر است. خروجی فرمان همچنان تحریک مؤثر است و به کالیبراسیون سیم‌پیچ واقعی نیاز دارد.
